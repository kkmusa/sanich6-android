# Открытие проекта и обновление в RuStore

Текущий выпуск: [2.8.4 — очистка текста «Отбор проб»](CHANGES_2_8_4_RU.md).

1. Распакуйте скачанный ZIP в новую папку.
2. В Android Studio выберите File → Open и откройте папку, где находятся settings.gradle.kts, build.gradle.kts и app/.
3. Разрешите Gradle Sync и дождитесь загрузки зависимостей. Для первой синхронизации нужен интернет.
4. При запросе SDK установите Android SDK Platform 36 и предложенные Build Tools через SDK Manager. В настройках Build, Execution, Deployment → Build Tools → Gradle используйте встроенную JDK Android Studio (JDK 17 или 21).
5. В app/build.gradle.kts установлены versionCode=34 и versionName="2.8.4". Если в RuStore уже загружена сборка с кодом 34 или выше, увеличьте код относительно максимального загруженного.
6. После успешной синхронизации: Build → Generate Signed Bundle / APK → APK (название пункта зависит от версии Android Studio).
7. Выберите существующий ключ подписи предыдущей версии. Пароли вводите только у себя. Выберите release.
8. Загрузите подписанный APK как обновление в существующую карточку RuStore.

Пакет com.example.sanich сохранён. Для обновления он должен совпадать с опубликованным приложением.

## Исправления конфигурации

- Каталог версий перенесён в стандартный gradle/libs.versions.toml.
- В корневом build.gradle.kts остаются объявления плагинов с apply false; конфигурация Android находится в app/build.gradle.kts.
- Явно подключены Kotlin Android, Compose и KSP с версиями.
- Используются AGP 8.13.2, Kotlin 2.2.10, KSP 2.2.10-2.0.2, Gradle 8.13, compileSdk 36.
- Восстановлены согласованные скрипты и файлы Gradle Wrapper; контрольная сумма JAR сверена с официальной, для дистрибутива закреплена SHA-256.
- Включён AndroidX.
- Изменения предыдущего выпуска касались конфигурации. В 2.8.3 добавлены масштабирование ВНР, сохранение позиции и расчёт напора — см. [описание обновления](CHANGES_2_8_3_RU.md).

Ключ подписи, пароли и local.properties в проект не включены. Этот архив — исходный код, а не подписанный APK.

- Gradle 8.13 запускается, плагины разрешены, конфигурация корневого проекта и app проходит проверку help.
