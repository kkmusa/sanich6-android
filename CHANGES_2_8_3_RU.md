# Оператор ДНГ — Android 2.8.3 (код 33)

В регламенте ВНР появились видимые кнопки **A−** и **A+**: масштаб от 75 до
300%, шаг 25%. Исходный документ состоит из изображений страниц, поэтому
увеличивается вся страница вместе с текстом, иллюстрациями, ссылками и
подсветкой. Вёрстка регламента сохраняется.

При увеличении и уменьшении сохраняется фактически читаемый фрагмент,
а не только номер страницы. Масштаб, страница и смещение внутри неё
сохраняются на устройстве и восстанавливаются при повторном открытии.
Кнопка «Оглавление» ведёт на страницу 2; нижний ползунок остаётся доступным.
Панель закладок удерживается в пределах экрана при увеличении.

**Закладки:** нажмите «Закладки» → «＋ Страница …». В списке можно открыть
страницу, изменить название кнопкой ✎ и удалить закладку кнопкой ×.
Дубликаты одной страницы не создаются. Существующее хранилище закладок
сохранено; интернет для чтения, поиска и закладок не требуется.

После ручного замера добавлен калькулятор **«Напор на частоте»**:

- Паспортный напор при 50 Гц — в метрах; рабочая частота — в герцах.
- Формула автора: H = H₅₀ × (f / 50)².
- Пример: 2100 × (54 / 50)² = **2449,44 м**.
- Подсказка «?» содержит формулу, обозначения и пример.
- Результат вычисляется автоматически, сохраняется в историю; поля сохраняются
  на устройстве. Пустые, отрицательные, нечисловые и бесконечные значения
  отклоняются; 0 Гц даёт 0 м при положительном паспортном напоре.

Включена совместимость java.time с Android 7 (API 24/25): это устраняет
найденную статической проверкой проблему дат/времени в ручном замере.
Версия на заставке и в «О приложении» теперь автоматически берётся из
настроек сборки. Электронный уровень не изменялся. Пакет com.example.sanich сохранён.

## Получение и выпуск

1. Распакуйте полный ZIP проекта в новую папку и откройте её в Android Studio.
2. Дождитесь успешной синхронизации Gradle.
3. Для RuStore: Build → Generate Signed Bundle / APK → APK → ваш существующий
   ключ → release. Используйте тот же ключ, что и у предыдущего выпуска.
4. Загрузите подписанный APK в существующую карточку приложения RuStore.

Установлены versionCode 33 и versionName 2.8.3. Если код 33 уже использован
в RuStore, следующий код должен быть больше максимального загруженного.
Ключи и пароли в проект не входят. APK release, собираемый GitHub Actions,
не подписан ключом владельца и требует локальной подписи перед RuStore.
