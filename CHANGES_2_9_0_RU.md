# Изменения версии 2.9.0

- Добавлен пересчёт производительности иностранных УЭЦН по закону подобия.
- Исходная частота по умолчанию — 60 Гц, требуемая — 50 Гц; обе можно изменить.
- Результат показывается в барр./сут и м³/сут и сохраняется в истории.
- В расчёт динамического уровня добавлен необязательный напор УЭЦН.
- При заполненном напоре сразу рассчитывается частота запуска; объединённый результат сохраняется в истории.
- Автоматический поворот отключён для всего приложения.
- В «Регламенте ВНР» добавлена отдельная кнопка ручного перехода между книжной и альбомной ориентацией.
